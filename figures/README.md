# Paper figure sources

`full_load_resource_20260920/` contains resource summaries, decisions, timelines, and sample-level accuracy traces. `ship_smoothed_case_20260920/` contains the ship-case raw values, smoothed values, plotted trace, seed metrics, and original builder.

The released CSV files provide numerical analysis inputs. The original builders also require external runtime profiles, manifests, and prediction bundles that are not included in this repository. They write generated analysis and figure files into their own directories. See each directory's README for the required inputs and interpretation of the figures.
