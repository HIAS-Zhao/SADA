# 三种子完整框架实验结果

本目录保存随机种子42、43、44的组级结果、逐种子结果、三种子汇总和协议校验记录。

## 冻结协议
- 对应主表四个模型、每模型5种方法、7档负载。到达率参考与seed42保持一致。
- Qwen2.5：固定基线rank8/alpha16/120步，Periodic等待20个样本；SADA使用固定候选与20%/0.005准入门槛。训练从初始基座开始，各种子使用相应SADA检查点和选中配置预测。
- Qwen3.5：每种子训练8个普通LoRA和2个固定EWC检查点；候选及测试顺序与seed42一致。80步候选使用同种子的实际检查点。
- RemoteCLIP/ResNet18：冻结主干特征、基座预测、推理时延；每种子训练所有分类头预算并产生预测。训练顺序种子为light42、light43、light44，分类头零初始化。数据划分与伪标签逐项检查一致。各预算耗时预热后取3次重复中位数。
- EWC使用相应种子的历史基座Fisher并计入历史测量时间；小模型Fisher重新计算。
- Qwen seed43/44使用GPU2/4进行训练和推理，耗时来自实际运行。seed42来自历史测量，当时可能有不同GPU竞争；三种子差异因此包含运行时差异，不仅是模型随机性。
- 固定数据划分下的训练随机种子重复，不是三次重新抽样划分。

## 文件
`../scripts/run_lane.py`及`../scripts/seed43/`、`../scripts/seed44/`脚本是训练入口；train_specialists.py训练小模型分类头；qwen25_replay.py准备选中配置并计分；eval_qwen25_missing.py生成选中配置预测；replay_bundles.py重放其余三模型；aggregate.py输出中文结果表。

逐种子结果.csv保存420个种子级单元格，三种子统计.csv保存140个均值/样本标准差单元格。论文同格式结果表.csv为中文宽表，结果预览.md用于展示。`COMPLETE.json`记录结果生成完成时间。

## 已通过检查
- 原OmniEarth seed42 105个单元格零误差重放。
- 原Qwen2.5 seed42 35个单元格与论文三位小数完全一致。
- 小模型train/val/test无交集，预测覆盖完整，验证伪标签准确率逐项重算，扰动测试标签不影响选择。

## 校验范围

校验覆盖40个Qwen检查点与全部小模型种子参数；945条组级结果汇总为420个种子级单元格和140个三种子统计单元格。

从仓库根目录运行 `python framework/scripts/verify_paper_results.py` 可从发布的组级CSV重算逐种子结果、均值和样本标准差。
